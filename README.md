# Mafia Black Gold 1.1 — پیش‌نمایش رابط کاربری

این مخزن فقط یک **پیش‌نمایش استاتیک و نمایشی** از ظاهر اولیه Mafia Black Gold 1.1 است.

## اجرا
فایل index.html را در مرورگر باز کنید یا GitHub Pages را برای این مخزن فعال کنید.

## فعال‌سازی GitHub Pages
1. وارد Settings همین مخزن شوید.
2. از منوی کناری Pages را باز کنید.
3. در بخش Build and deployment گزینه **Deploy from a branch** را انتخاب کنید.
4. Branch را روی main و پوشه را روی /(root) قرار دهید.
5. Save را بزنید و منتظر تکمیل انتشار بمانید.

نشانی معمول پس از انتشار موفق:
https://shabnam2015iran5-creator.github.io/mbg-1-1-preview/

## محدودیت‌ها و امنیت
- این پروژه به API، سرور بازی، دیتابیس، ورود واقعی، پرداخت، جواهرات یا گفت‌وگوی زنده متصل نیست.
- اتاق‌ها و نام میزبان‌ها داده‌های ساختگی و صرفاً نمونه هستند.
- هیچ اطلاعات حساب، رمز، توکن، کلید API یا داده بازیکنان واقعی در این مخزن قرار نمی‌گیرد.
- این مخزن از کد خصوصی سرور یا فایل‌های مخزن اصلی کپی نمی‌کند.
- این پیش‌نمایش را نباید سرور عملیاتی یا نسخه قابل بازی معرفی کرد.

مخزن اصلی و داده‌های واقعی بازی جدا و خصوصی باقی می‌مانند.
